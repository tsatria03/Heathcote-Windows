**Don't write down each release the dev makes.** No note in `aidocks/` and no line in `README.md` says which versions went out, when, with how many changelog entries, or with which zip, tag or release commit.

**Why:** The dev's standing rule, adopted for this project on 2026-10-19. People do not need to see each release listed.

**How to apply:**
- When the dev says they released, answer in chat. Don't offer to record it.
- Version numbers used only as examples of the format, such as `26.10.19-1`, are fine.
- The changelog's own version headings stay as they are.
